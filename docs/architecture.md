# البنية

```
 [الجهاز ESP32] --USB--> [برنامج اللابتوب MindTrace]  --مجلد جلسة-->  [bridge]  --POST-->  [backend]  <--/api--  [frontend]
   مايك + شاشة            صوت -> نوتس -> نصوص                          JSON + صوت            FastAPI + SQLite         React (Vite)
                          (Audar + Whisper احتياط)                     token حسابك           حسابات + تجارب + تعاون
                                                                                              + DeepSeek (من هنا بس)
```
خادم واحد يقدّم الـ API والواجهة المبنيّة (`frontend/dist`)، فما في CORS ولا cookies معقّدة.

## الكيانات (قاعدة البيانات، SQLite)
| الجدول | وش فيه | العلاقات |
|---|---|---|
| `users` | الاسم، البريد (فريد)، `public_id` (MT-XXXXXXXX فريد)، hash كلمة المرور | |
| `auth_sessions` | جلسات الدخول (hash الـ cookie token + انتهاء) | → users |
| `api_tokens` | tokens الجسر (hash فقط) | → users |
| `experiments` | العنوان، الحالة، الأصالة، الوسوم، نتيجة DeepSeek، `session_id` (لو جاءت من تسجيل) | owner → users |
| `notes` | النص، النوع، `source` (يدوي/مسجّل)، `text_source` (إنسان/ASR)، `meta` (ثقة ASR وغيره) | → experiments, → users (الكاتب) |
| `collaborators` | من له وصول للتجربة ومن أضافه | → experiments, → users |
| `notifications` | المستلم، الفاعل، النوع، مقروء/لا | → users, → experiments |
| `sessions` | `session.json` الأصلي كما وصل + قائمة ملفات الصوت | (owner, session_id) → experiments |

كل البيانات مرتبطة بـ `owner_id`/العضوية. الأسئلة كلها تمر على `require()` اللي يرجّع 404 لغير الأعضاء.

## قرارات
- **JSON هو المدخل.** الخادم ما يعيد تحويل الصوت لنص؛ يثق بما وصل من برنامج اللابتوب ويحفظه كما هو (ويضيف عليه تجارب ونوتس).
- **الـ AI يقترح ولا يعدّل.** أي تصحيح نص يبقى اقتراح بجنب النص الأصلي، والباحث يقبله بزر.
- **نص عدّله إنسان ما يُستبدل أبداً** لو أُعيد رفع الجلسة.
- **الخصوصية:** DeepSeek يستلم نص النوتس بس، والمفتاح في `.env` على الخادم. بدون مفتاح كل شي يشتغل ما عدا الرؤى.
- **SQLite** للبروتوتايب: ملف وحد، بدون تثبيت. لو كبر المشروع نبدّل القاعدة بدون تغيير العقد.
- **الأمان:** scrypt، cookie HttpOnly، حماية CSRF بهيدر، حد محاولات الدخول، أسماء الصوت من قائمة بيضاء، حد لحجم الرفع، المستخدم يشوف بياناته بس.
