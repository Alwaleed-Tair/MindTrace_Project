# MindTrace UML

One class diagram of the whole system (hardware device, laptop application, web platform, external services),
drawn from the actual code.

- `MindTrace_UML.puml` - source (PlantUML)
- `MindTrace_UML.png` / `.svg` / `.pdf` - rendered

Re-render after a change: `java -jar plantuml.jar -tpng -tsvg docs/uml/MindTrace_UML.puml`
